# Rul's DBD Builds

Website for **showcasing** and **storing** builds a variety of Dead by Daylight builds.


### Explore

From the home page, you can **browse** the available builds for killers and survivors.

### Create

Open the **Builder** to create a custom build:

1. Choose whether you want to create a killer or survivor build.
2. Select the corresponding killer or survivor group.
3. Choose four perks and the alternative perks.
4. Add a name and an author alias to your build.
5. Sign in and submit the build.

*Note: After you submit it, the build is **reviewed** before appearing on the website.*

### Learn

Open any perk to **read** its description and learn more about its effects, bonuses,
and activation conditions.

## Inspiration

This project is heavily inspired by [Mr.Tipson's repository](https://github.com/MrTipson/otz-builds), from which **styles** and **aesthetics** were originally taken, his work was also key for scrapping the info about **perks** and **characters** from the [Dead By Daylight Wiki](https://deadbydaylight.wiki.gg/).
